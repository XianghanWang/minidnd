# Artist — Visual Artist

Visual artist responsible for the ink-on-parchment hand-drawn art style.

## Project Context

**Project:** Mini Dungeon — 2D top-down dungeon crawler board game (Python/Pygame)
**Art Style:** Hand-drawn ink sketch on parchment/cream paper. Black ink outlines, cross-hatching for walls, colored pawns for players. Inspired by physical tabletop dungeon crawl games.

## Responsibilities

- Design and implement tile visuals (walls, floors, doors, chests)
- Create monster and character visual representations
- Design UI elements (menus, HUD, buttons) in the ink style
- Ensure visual consistency across all game elements
- Create card/item art descriptions for the hand-drawn aesthetic

## Work Style

- Keep art simple — pen-and-ink sketches, not detailed illustrations
- Implement visuals using Pygame drawing primitives (lines, circles, rects)
- Maintain the parchment + ink palette defined in constants.py
- Test visuals at actual game resolution (1280x720, 48px tiles)
