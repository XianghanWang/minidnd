# UI and Visual Style

## Art Direction
- **Ink-on-parchment hand-drawn style**
- Inspired by physical tabletop dungeon crawl board games
- Reference: pen-and-ink sketches on cream paper with colored pawns

## Color Palette
- **Background**: Cream/parchment (245, 235, 220)
- **Ink (primary)**: Dark brown-black (35, 30, 25)
- **Ink (light)**: For details and subtitles (100, 90, 75)
- **Walls**: Dark ink fill with cross-hatch pattern
- **Floors**: Light cream with subtle crack details
- **Grid lines**: Pencil-weight, subtle (180, 160, 130)
- **Player pawns**: Colorful (blue, purple, green) — like board game pieces
- **UI panels**: Dark ink background with cream text

## Tile Rendering
- Walls: Solid dark fill + diagonal cross-hatching
- Doors: Wooden plank style with ink outline and handle
- Locked doors: Same + lock icon (circle + rectangle)
- Chests: Hand-drawn box with lid arc and latch
- Road: Cream with occasional subtle crack lines

## Player Appearance
- Pawn shape (like physical board game pieces): cone body + round head + oval base
- Colored per character type
- Player number on body

## Monster Appearance
- Circular body with ink outline
- Two ink-dot eyes + mouth line
- Boss gets horn/crown details
- Type letter below face
- Health bar above (thin ink-outlined)

## Screen Layout
- **Resolution**: 1280×720
- **Tile size**: 48×48 pixels
- **Bottom panel** (120px): Player stats, AP bar, action buttons
- **Top-right**: Round counter, cards drawn
- **Top-center**: Phase indicator (whose turn)
- **Right side**: Message log (last 6 messages)

## Screens
1. Main Menu (title + start/quit)
2. Mode Select (single/multiplayer)
3. Character Select (pick characters, set player count)
4. Game (dungeon view + HUD)
5. Game Over (win/lose message + return to menu)
